# GESBANK

Versión estática de demostración lista para GitHub Pages.

## Publicar

1. Crear un repositorio, por ejemplo `GESBANK`.
2. Subir **todos los archivos de esta carpeta** a la raíz del repositorio.
3. En GitHub entrar en **Settings → Pages**.
4. En **Build and deployment**, seleccionar **Deploy from a branch**.
5. Seleccionar la rama `main` y la carpeta `/ (root)`.
6. Guardar y esperar la publicación.

La aplicación funciona como demo usando `localStorage`, por lo que no necesita backend para esta primera prueba.

**Importante:** esta versión no mueve dinero real. Para producción se debe incorporar autenticación, backend seguro, base de datos, auditoría y una integración financiera autorizada.
